## 2026-11-03 — 注入预算可由用户自定义（feat-11-03-configurable-inject-budget）

- 用户验收通过并授权归档；任务完成并解绑当前会话。
- 需求：`.trellis/doc.json` 正文注入的预算原来是写死的常量（8KB/文件、32KB/合计），不同项目需求差异大却只能改源码；用户要求「预算可以由用户自定义」，单位指定为 KB，并要求「项目文档」视图里也能直接改。
- 实现：
  - `lib/spec.js`：新增 `resolveDocBudget(settings, override)` 作为唯一的优先级 + 夹紧 + 回退实现（`doc.json` 的 `budgets` > 设置页 > 内置 8/32；硬顶 128KB/512KB、下限 1KB，非法值逐级回退，合计封顶单文件）；新增 `parseBudgetDraft()` 只做「用户输入 → 保存」的报错校验（不夹紧）；`planDocBudget(entries, budget = DEFAULT_DOC_BUDGET)` / `renderDocBodies` / `evaluateDocConfig` / `readDocConfigSnapshot` / `saveProjectDocConfig` / `resolveSpecIndexInstruction` 全部接预算，提示词头与截断标记动态输出真实生效值。
  - `lib/meta.js`：`docFileBudgetKB`（8）、`docTotalBudgetKB`（32）两个 volatile 数字字段。
  - `lib/index.js`：`specIndexCache` 键改为 `root\0fileKB:totalKB`（改设置立即失配），新增 `invalidateSpecIndex(root)` 保存后整根失效；doc-config 路由接受/校验 `budgets` 载荷（非对象非 null → 400）。
  - `lib/client.js`：设置卡片两个数字字段；「项目文档」视图新增「注入预算」两个 KB 输入框（留空=继承、非法行标红并禁用保存、改动即防抖 preview），进度条与「将截断至 N KB」改为读服务端生效值与该文件真实 `limit`，移除 8KB/32KB 硬编码文案。
  - `.trellis/doc.json`：可选 `budgets: { fileKB, totalKB }`，只写要覆盖的字段；两项留空即删键。
- 验证：`node --test` **317/317**；真实渲染冒烟（默认 8/32、设置 16/64、项目覆盖 4/12、离谱值 10240/8 → 夹成 8/8）。
- 独立评审（子代理，未参与实现）结论 pass，4 条 minor 全部修掉：`saveProjectDocConfig` 未转传 `configPath`；截断徽章用配置上限而非该文件真实 `limit`；快照回显原始 KB 导致「自己校验不过自己的预填值」并锁死保存；单文件上限可大于合计上限渲染出矛盾头部。另修：`formatBudgetKB` 改向下取整、草稿未提 `budgets` 时保存不再误删已有覆盖。
- 规范沉淀：`web-ui` 新增第 43 条（预算可配置约定：唯一解析点、视图写 `doc.json`、回显夹紧值、缓存键含预算）；`task-engine` §7 与「项目文档入口」两条改为 KB 词表 + 优先级 + 硬顶，替换已删除的常量说明。
- 提交：`90bf771`（业务实现）→ 本次归档提交。
- 归档位置：[prd / design / review](../tasks/archive/2026-11/feat-11-03-configurable-inject-budget/prd.md)。
