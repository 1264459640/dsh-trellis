# Refactor Design: 看板UI重构（列表与看板解耦及图标化）

status: approved
mode: standard

## 行为等价与兼容性声明
- **接口等价**：不改动任何后端 HTTP 接口契约（`/trellis-workflow/api/board`, `/trellis-workflow/api/bind`, `/trellis-workflow/api/task-state`）。
- **交互语义等价**：任务选择、会话激活/取消激活、回车自动填入/降级剪贴板、归档展开/折叠等核心交互行为完全保持一致。
- **技术依赖守则**：直接在 `lib/client.js` 内自包含轻量 SVG 渲染系统，不引入任何重型外部 npm 依赖，兼容现有的 Harness Web 插件运行时。

## 重构方案设计

### 1. 轻量内联矢量图标系统 (SVG Micro-System)
在 `lib/client.js` 中构建自包含的 `renderSvg(name, props)`，提供统一 16x16 / 14x14 规范的矢量图标：
- `refresh`: 顺时针旋转箭头图标（带 hover 微旋转交互）
- `maximize`: 现代展开/全屏视窗图标
- `close`: 极简平滑关闭叉号图标
- `search`: 放大镜检索图标（嵌入搜索框左侧）
- `fileText`: 现代折角文档/代码文件图标
- `externalLink`: 外链跳转微型小图标
- `folder`: 归档文件夹图标
- `chevronRight` / `chevronDown`: 折叠三角箭头图标
- `play` / `send`: 推进任务操作图标
- `pin` / `radio`: 会话绑定状态图标
- `alertTriangle`: 阻塞警告图标
- `clock`: 待验证时钟图标
- `checkCircle`: 步骤完成实心对勾图标

### 2. 小窗视图：重构为高密度垂直任务列表 (Master-Detail List)
- 放弃原本在 400px 内强行并排“规划中/进行中”两列的做法。
- 改为垂直单列高密度任务列表：
  - 任务项完整展示 2 行标题，不再使用单行暴力截断。
  - 左侧展示工作流色条（功能/缺陷/重构）。
  - 下方展示 slug（等宽字体）及进度徽章。
  - 右侧展示阶段胶囊 Badge（柔和背景与圆角）。
- 顶部工具栏图标化：右侧保留微型刷新图标与展开图标，整洁紧凑。

### 3. 大看板视图：多横向滚动条治理与泳道聚焦
- 顶部工作流 Filter Tab 升级：显示每个分类的任务数量 Badge（如 `全部 (3)`、`重构 (1)`）。
- 泳道容器重构：
  - 当过滤为具体工作流时（如重构），全屏横向展示该工作流各阶段列，统一外层滚动条，彻底消除 3 根原生滚动条并发的问题。
  - 滚动条样式使用 `scrollbar-width: thin` 与极简透明轨道，避免老旧灰色滑块。
- 看板卡片质感提升：
  - 柔和微阴影（`0 1px 3px rgba(0,0,0,0.06)`）+ 悬浮轻微上浮（`-1px`）。
  - 选中态采用左侧 3px 品牌色条与微蓝/深色底板，替代突兀的纯蓝线框。

### 4. 任务详情面板：工作台专业化与操作层级优化
- 阶段流转指示器（Step Tracker）：升级为横向节点连接线（完成节点绿勾、当前节点高亮高精呼吸灯、未开始节点灰圆）。
- 产物文件列表：改造为标准文件列表项，带小文件图标，Hover 出现外链复制/跳转图标，提供清晰点击反馈。
- 底部操作按钮：
  - **推进任务**：设为主操作实心高亮按钮（Primary Solid Button），带有操作图标，视觉重心突出。
  - **设为当前会话激活**：次级按钮（Secondary Button），弱化边框，避免多主色打架。

## 执行步骤与验收（映射至 checklist.yaml 与 task.json.steps）
- `step-1`: 封装自包含内联 SVG 图标集并替换纯文本/Emoji 按钮 [ai]

- `step-3`: 大看板泳道容器与工作流联动重构 [ai]
- `step-4`: 详情面板专业工作台化与主次层级升级 [human]
