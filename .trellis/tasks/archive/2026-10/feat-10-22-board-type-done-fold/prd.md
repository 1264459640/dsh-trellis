# 大看板：强化任务类型区分 + 已完成分组可折叠

## 背景

全屏大看板（`KanbanExpandedModal`，lib/client.js）现状：
- 类型列只是一段 12px 灰色文字（`taskTypeLabel`），和右侧"阶段"列样式完全相同，扫一眼分不出 功能 / 缺陷 / 重构。
- 「已完成 · 归档」分组与进行中/规划中平铺，任务多了以后把活跃任务挤到需要滚动。

约束：视觉语言 v2 是单强调色设计（品牌蓝 + 仅 blocked/待验证用红黄），本次不应重新引入"彩虹标签"。

## 范围

只改全屏大看板；紧凑浮层不动。不改后端 payload。

## 需求

1. 类型徽标：类型列从纯文字改为带边框的小徽标 + 每类一个单色图标（功能 / 缺陷 / 重构各不相同），颜色保持中性灰，不新增色相。
2. 已完成分组可折叠：
   - 分组标题变成可点击的折叠开关（带 chevron，`aria-expanded`）。
   - 默认折叠，标题仍显示数量。
   - 搜索框有内容时自动展开（避免搜到的结果被藏起来）。
   - 折叠状态只保存在组件内存，不持久化。
3. 进行中、规划中分组行为不变。

## 验收

- 三种类型在行内用不同图标 + 徽标展示，主题测试（对比度 / 无不存在的 token）仍通过。
- 打开大看板时已完成分组折叠，只显示「已完成 · 归档 N」；点击展开/再收起。
- 输入能匹配已完成任务的搜索词时，已完成分组自动展开显示结果。
- `npm test` 全绿；新增测试覆盖默认折叠、点击展开、搜索时展开、类型徽标渲染。

## Non-goals

- 不按类型再分泳道、不给类型上彩色。
- 不改紧凑浮层、不持久化折叠状态。
