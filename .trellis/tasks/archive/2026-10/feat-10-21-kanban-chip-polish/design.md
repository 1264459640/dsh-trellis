# Design：看板与徽标视觉及交互体验升级

> v2（第 7 轮）：用户看过三个对比原型（`prototype/kanban-chip.prototype.html`）后选定 **方案 A「安静列表 · 当前任务置顶」**，并要求**保留具体步骤**。本文件取代 v1 的「凹槽 + 浮起卡片」方案。v1 已实现但被用户评价为"还是有点丑"。

## 1. 视觉原则

- **只用一个强调色**：品牌蓝只表示"当前会话 / 进行中 / 已完成的步骤"。类型用无彩色文字（功能 / 缺陷 / 重构），不用彩色徽章。
- **异常才上色**：红只表示阻塞，琥珀只表示待验证。其余状态都是灰阶。
- **先排版，再装饰**：列表行用两层文字（标题 + 淡色 meta），不用徽章堆叠。动作按钮只在 hover / 选中 / 键盘聚焦时出现。
- **选中态**：用一层很淡的 hover 底色（列表）或品牌色 9% 底色（大看板表格行）。不用描边、竖条、圆点、阴影浮起。
- 亮色和暗色共用同一套 token。

## 2. 徽标 TaskChip

- 结构：`● 阶段 任务标题 ⌄`。状态点用品牌色，进行中时带呼吸光晕；阶段名为灰色；标题最多 200px。不显示类型。
- 外观：默认透明无边框；hover 或展开时显示 hover 底色；箭头旋转。
- 加载中显示骨架；无任务显示空心点 + "选择任务"；失败显示红点 + "重试"。

## 3. 迷你看板 Popover（宽 400）

1. **头部**："当前会话任务"小标题 + 展开大看板图标。
2. **当前任务卡**（well 底）：
   - `● 进行中  类型 · 阶段`
   - 标题（14.5px）
   - 进度条 + `x/y 步骤`
   - **步骤清单**：嵌在卡内的白色子卡片，紧凑模式默认把已完成步骤折叠成一行"已完成 N 个步骤"，只展开最后一个已完成步骤和其后的所有步骤。当前步骤加粗，内联显示验收标准或阻塞原因。人工步骤带"人工"小标签。步骤多于 3 个时提供"展开全部 / 收起"。
   - 动作：主按钮"推进任务"（品牌色，注入 Composer，沿用 `pushPromptFor`）+ 次级"解除绑定"（= bind(null)）。
   - 无当前任务时，这张卡改为空态提示"从下面选一个任务绑定到当前会话"。
3. **分组列表**：进行中 / 规划中，每组一个小标题加数量。行为两层文字：标题；`类型 · 阶段 · x/y · 阻塞/待验证`。行末 ▶ 只在 hover / 选中 / 聚焦时可见（busy 时禁用）。当前任务不进入列表（它在卡片里）。
4. **底部**：左边"已归档 N ›"（打开大看板），右边 `↑↓ 选择 ↵ 绑定` 键位提示。

保留的契约：每行恰好一个行内动作，不嵌套 button，busy 时禁用，点击时 stopPropagation，▶ 先 select 再 activate。当前任务的 ■ 解绑入口改到卡片里的"解除绑定"按钮（aria-label 仍用 `deactivate + ': ' + title`）。

## 4. 展开大看板

- 顶栏：`任务` + 文字型筛选 tab（全部 / 功能 / 缺陷 / 重构，各带数量，选中项用 hover 底色加粗）+ 搜索框（well 底，⌘K）+ 关闭。
- 主体左侧是**分组表格**（进行中 / 规划中 / 已完成），列为：状态点 · 标题（下面是 mono slug）· 类型 · 阶段 · 进度条 · `x/y` 或异常标记。选中行用品牌色 9% 底色。
- 右侧详情（360px）：
  - `类型 · 状态 · 当前会话` 小字，标题，slug
  - 动作：当前任务 → 推进任务 + 解除绑定；其他未完成 → 设为当前任务；已完成 → "已归档 · 只读"
  - **阶段**：分段条（完成段为品牌色，当前段为 45%）+ 下方阶段名，当前阶段加粗
  - **步骤**：`步骤 x/y` + 细进度条 + **完整步骤清单**（同上，不折叠）
  - **产物**：文件行，hover 时显示外链图标，点击沿用 `openArtifactFile`
- 删除原来的三泳道视图和视图切换：用户选的是 A 的表格形态。泳道依赖的 `board.tracks` 继续用于阶段分段条。

## 5. 步骤清单组件 `StepList`

- 输入：`task.steps`（宿主下发，已归一化）、`compact`。
- 当前步骤 = 第一个非 completed 的步骤（和宿主的 `activeStep` 在常见情况下一致；展示用途，不用于拼装推进 prompt，推进仍走 `pushPromptFor(task)` → `task.activeStep`）。
- 图标：completed = 品牌色实心勾；in_progress / 当前 = 品牌色圆环加点；verifying = 琥珀时钟；blocked = 红色警告；pending = 灰环。图标之间用 1px 竖线串起，已完成段为品牌色。
- 人工步骤：`verification === 'human'` 时显示"人工"标签。

## 6. 实现方式

- 继续用模块级 `ensureStyles()` 注入 `.tw-*` 作用域样式表，负责 hover / focus-visible / 动画 / reduced-motion。颜色仍写在内联 style 里，供对比度测试读取。
- TB token 增加 `brandTint`（品牌色 9%）。删除不再使用的 `raised` 浮起选中逻辑、`Segmented`、`KanbanLaneCard`、`KanbanArchive` 等 v1 组件。
- 不改后端（lib/board.js、lib/index.js、lib/state.js）。

## 7. 测试

- 对比度矩阵（3 主题 × 3 选中 × 视图）继续覆盖：popover、表格（取代 lanes/list）。
- 行内动作契约测试按新结构更新：非当前行恰好一个 ▶；当前任务的解绑按钮在卡片里且恰好一个；busy 禁用；stopPropagation；select → activate 顺序。
- 新增：步骤清单渲染（当前步骤加粗 + 验收文本；blocked 显示原因；compact 折叠已完成步骤）；选中行不带品牌色描边。

## 8. 风险与回滚

- 去掉泳道视图属于可见功能删减，已由用户选定的方案 A 确认。
- 原型文件只做留档，不进主分支。
- 回滚：改动集中在 lib/client.js 和测试，直接还原即可。
