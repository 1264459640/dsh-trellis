# 精致小巧的 Trellis 任务看板 (Mini Kanban) — 复审

## 设计评审要点

1. **左侧活跃看板**：
   - 仅保留「规划中」和「进行中」两列，符合「精致小巧」要求
   - 每张卡片展示标题、类型徽章、当前阶段、高亮「本会话激活」状态
   - 右侧详情面板实时同步选中卡片

2. **底部按月折叠归档树**：
   - 按 `YYYY-MM` 分组历史任务（天然符合 Trellis 命名规范）
   - 默认折叠，只显示父文件夹标签，点击展开查看具体任务
   - 已归档任务只读，禁止激活，符合「历史任务收纳」要求

3. **右侧详情面板**：
   - 展示任务完整元数据（标题、类型、阶段、产物状态）
   - 显式激活/解绑按钮（通过会话 ID 隔离实现，无覆盖风险）

4. **交互机制**：
   - 浏览 = 查看详情（只读）
   - 激活/解绑 = 显式按钮触发
   - 已归档任务只读

5. **技术规范**：
   - 使用 DSH 设计变量（`--dsw-alias-*`）
   - 毛玻璃半透明浮层 + 细腻动画
   - 显式会话 ID 隔离（每个会话有独立指针文件）
   - 历史任务按月折叠，长期可维护

## 复审结论

✅ **通过**。设计符合第一性原理，结构清晰，交互合理，长期可维护。
