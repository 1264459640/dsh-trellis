# 精致小巧的 Trellis 任务看板 (Mini Kanban) — 产品需求

## 目标

在 DSH 会话头部右侧注入一个**精致、小巧的 Trellis 任务看板**，让用户无需离开当前上下文，就能快速概览项目任务状态，并通过显式操作绑定/解绑会话激活任务。

## 核心结构

- **左侧**：**活跃看板**（仅保留「规划中」和「进行中」两列）
  - 每张卡片显示任务标题、类型徽章、当前阶段、高亮「本会话激活」状态
  - 右侧详情面板实时同步选中卡片

- **底部**：**按月份折叠归档树**
  - 按 `YYYY-MM` 分组历史任务
  - 默认折叠，只显示父文件夹标签，点击展开查看具体任务
  - 已归档任务只读，不允许激活

- **右侧**：**统一详情面板**
  - 展示任务完整元数据（标题、类型、阶段、产物状态）
  - 显式激活/解绑按钮（通过会话 ID 隔离实现，无覆盖风险）

## 交互机制

1. **浏览**：鼠标悬停/点击卡片 = 查看详情（只读）
2. **激活**：点击「设为当前会话激活」按钮 = 显式绑定会话指针（`sess_<id>.json`）
3. **解绑**：点击「取消当前激活」按钮 = 显式清除指针
4. **已归档任务**：只读展示，禁止激活

## 技术规范

- 使用 DSH 设计变量（`--dsw-alias-*`）
- 毛玻璃半透明浮层 + 细腻动画
- 显式会话 ID 隔离（每个会话有独立指针文件）
- 历史任务按月折叠，长期可维护
