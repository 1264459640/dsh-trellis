# Feature PRD：工作台视觉高保真还原

## 目标与用户价值
将 DSH Web GUI 中 dsh-trellis 的展开任务工作台视觉从当前偏紧凑、浅灰边界过强、信息密度不均的呈现，继续还原至用户给出的参考效果图（`.dsh/generated/dsh-auxiliary-1788782790255-1.png`）：在不改变任务数据和既有操作语义的前提下，获得更接近 Linear/Vercel 风格的宽屏三泳道工作台与右侧详情检查器。

## 已确认事实
- 用户确认需要继续执行视觉还原；参考图为 `.dsh/generated/dsh-auxiliary-1788782790255-1.png`，当前实现截图为本轮聊天附件。
- UI 实现在 `lib/client.js`；展开工作台由 `KanbanExpandedModal`、`KanbanLaneCard`、`KanbanDetails` 渲染，设计令牌集中于 `TB`。
- 当前实现已具备搜索、类型筛选、看板/列表切换、三泳道、卡片选中、详情面板、阶段流水线、产物列表、步骤进度等行为。
- 工作区已存在与本任务无关或尚未提交的修改，实施时不得覆盖或回退这些改动；仅在已有设计代码基础上做最小必要的视觉调整。

## 范围
### In Scope
- 仅对展开工作台（`KanbanExpandedModal`）及其直接复用的泳道卡片和详情面板进行视觉、布局、响应式尺寸和层级调整。
- 调整外层暗色遮罩与白色圆角工作台外壳，使其在桌面宽屏中接近参考图的占屏比例、20px 左右圆角、柔和环境阴影和顶部工具栏留白。
- 对齐搜索框、筛选胶囊、分段视图切换、关闭按钮的尺寸、间距、色彩与选中态。
- 对齐三泳道的列宽比例、列间距、列头、独立滚动、卡片留白、状态点、类型标签、slug、阶段标签、进度条与选中态。
- 对齐右侧详情面板的固定宽度、垂直分割线、区块层级、主操作、阶段流水线、产物行和步骤概览的视觉规格。
- 保持列表形态可用，并让它继承统一 token 和不破坏布局。

### Out of Scope
- 不新增或移除任务操作，不改变 API、数据契约、任务状态机、筛选/搜索逻辑或国际化文案语义。
- 不修改 DSH 宿主 Web shell、启动替代服务器、引入第三方依赖或独立样式框架。
- 不处理本工作区中本任务之外的未提交修改。
- 不以像素绝对坐标强制固定布局；小屏幕继续允许合理换行与收缩。

## 验收标准
- [ ] 在 DSH GUI 刷新后的展开工作台中，外层深色遮罩、白色圆角窗口、工具栏、三泳道和常驻右侧检查器的总体比例与参考图一致，且无溢出或重叠。
- [ ] 顶部搜索、筛选、视图切换、关闭按钮在视觉权重、尺寸和间距上接近参考图；当前选择仍清晰可辨。
- [ ] 任务卡片有正确的规划灰、进行中蓝、完成绿状态语义；完成卡展示满格绿进度与勾选，选中卡展示蓝色边框/轻微发光和指示点。
- [ ] 详情面板有清晰的区块分隔和层次，阶段流水线、产物、步骤进度可读且不破坏已有功能。
- [ ] 搜索、筛选、看板/列表切换、选中任务、激活/解绑、发送到聊天、关闭等既有行为无回归。
- [ ] `node --check lib/client.js` 与 `npm test` 通过；人工在现有 GUI 刷新后进行参考图对照。

## 约束与风险
- `lib/client.js` 是 client bundle 源文件；改动生效需要按该插件的实际打包/开发流程重建。仅当同一 checkout 内 `pnpm run dev:web` 正在运行时，client-plugin HMR 才能无刷新更新；否则需构建受影响 Web 产物并刷新现有 GUI。
- 当前截图和参考图画布尺寸不同，验收以桌面断点下的结构、比例、层级和状态语义为准，而非逐像素截图比对。
- 工作台依赖 DSH 注入的 `window.__DSH_BOOT__`，不启动替代 Vite 服务作为验证手段。
