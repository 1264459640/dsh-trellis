# Feature PRD

## 背景
当前任务看板 UI（工作台看板/工作台列表/侧栏紧凑列表三种形态）与目标效果图差距较大：工具栏、卡片与行结构、选中态、进度与步骤呈现、右侧详情面板、紧凑小窗头部与分组等均与效果图不一致。前序任务 feat-09-08-restore-target-ui 已完成两轮还原并停在 check 阶段，人工对照后判定还原度仍不达标；本任务以三张效果图为唯一视觉基准重新还原。

参考效果图（工作区只读）：
- `.dsh/generated/dsh-auxiliary-1788773587554-1.png` — 工作台 · 列表模式（表格式行 + 右侧详情面板）
- `.dsh/generated/dsh-auxiliary-1788782242019-1.png` — 侧栏紧凑列表小窗（选中行浅蓝底 + 左蓝竖条 + 右蓝点）
- `.dsh/generated/dsh-auxiliary-1788782790255-1.png` — 工作台 · 看板模式（三泳道卡片 + 右侧详情面板）

## 范围
### In Scope
- 工作台顶栏：搜索框（含 ⌘K 提示）、筛选胶囊（全部/功能/缺陷/重构，选中为黑底白字、**不显示计数**）、视图切换分段控件（工作台 + 看板/列表，选中项黑底）、关闭按钮
- 看板模式：三泳道（规划中/进行中/已完成·归档，泳道头含计数胶囊）、卡片四行结构（①状态点+类型徽章 ②标题 ③等宽 slug ④进度条与 x/y 步骤同行；完成卡片右侧绿色圆形勾）、选中卡片（浅蓝底 + 蓝边框 + 右侧蓝点）
- 列表模式：表格式行（状态点、标题、等宽 slug、类型徽章、阶段徽章如「实现（impl）」、步骤胶囊「3/5 步骤」）、选中行样式同看板选中态
- 侧栏紧凑列表小窗：头部「Trellis 任务看板」+ 筛选胶囊同行 + 展开 + 关闭图标；行=标题+类型徽章+阶段徽章；选中行浅蓝底+左蓝竖条+右蓝点；底部提示「仅展示，不直接改状态」
- 右侧详情面板：激活任务区（标题+类型徽章+slug+黑色「激活任务」按钮；归档任务为只读提示）、阶段流水线（编号圆节点+连接线，已完成为勾）、产物列表（等宽文件名+打开按钮）、步骤清单（x/y 步骤标题+进度条+「已完成 n 个步骤，共 m 个步骤」+勾/空心圆条目）
- 视觉 token：圆角、间距、字号、颜色（黑底胶囊、选中蓝、完成绿、辅助灰）对齐效果图

### Out of Scope
- 数据契约、task.json schema、后端 API（/trellis-workflow/api/*）行为变更
- 效果图未出现的新交互（拖拽、批量操作、排序等）
- 设置页及其他插件界面的改动
- 效果图示例数据本身（任务标题/slug 为样例，不作为验收依据）

## 验收标准
- [ ] 工作台看板模式刷新后与效果图 3 逐区一致：顶栏、三泳道头计数、卡片四行结构、进度条与步骤同行、完成绿圆勾、选中卡片浅蓝底蓝边框右蓝点
- [ ] 工作台列表模式与效果图 1 一致：行六列结构（点/标题/slug/类型/阶段/步骤）、选中行样式、右侧详情面板联动
- [ ] 侧栏紧凑列表与效果图 2 一致：头部行布局（标题+筛选+展开+关闭）、行结构、选中行左蓝竖条、底部提示文案
- [ ] 右侧详情面板与效果图一致：激活任务区（黑色激活按钮/归档只读提示）、编号节点流水线、产物行、步骤清单进度条与圆勾
- [ ] 筛选胶囊选中态为黑底白字且不显示计数；视图切换选中项为黑底
- [ ] 现有交互不回归：搜索、筛选、视图切换、卡片/行点选、产物打开、任务激活、关闭/展开均可用
- [ ] `node --check` 与 `npm test` 通过；client 产物构建成功并在现有 GUI 刷新后可见效果

## 约束与风险
- client.js 为单文件 webview（约 131KB）：改动限于渲染模板与样式，不新增/修改消息协议字段（如确需新增必须在 design 中列明）
- 效果图为示例数据：验收以「结构与样式」为准，不以具体文案内容为准
- 风险：过度贴合效果图可能破坏窄屏/滚动行为；需保留或等价替换现有窄屏滚动规则
